Rutuja Naik — DevOps & Cloud Engineer Portfolio
================================================

Files:
- index.html — complete responsive portfolio (HTML + CSS in one file)

How to run:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, Firefox, or any modern browser.
3. No server, Node.js, npm, or build step is required.

Internet:
The page works locally without external assets. Google Fonts are loaded when internet is available; the browser falls back to system fonts if offline.
