# Rutuja Naik — DevOps & Cloud Engineer Portfolio

A responsive portfolio built with plain HTML, CSS and JavaScript. No build tools or package installation are required.

## Files

- `index.html` — portfolio content and page structure
- `styles.css` — responsive styling, theme variants and motion effects
- `script.js` — mobile navigation, theme toggle, scroll progress, reveal animations and project filters
- `assets/rutuja-naik.jpeg` — supplied profile photo
- `assets/Rutuja-Naik-Resume.pdf` — supplied resume; used by the Download Resume button
- `assets/favicon.svg` — portfolio favicon

## Run locally

1. Extract the ZIP file.
2. Open `index.html` in a modern browser. For a local server, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a GitHub repository. For a user site, use `Rutuja-Naik07.github.io`; alternatively use a project repository such as `rutuja-portfolio`.
2. Upload the contents of this folder to the repository root (the `index.html` file should be at the root, not inside another nested folder).
3. Commit and push the files to the default branch.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select your default branch (usually `main`) and folder `/ (root)`, then click **Save**.
7. Wait for the Pages deployment to complete. GitHub will show the published URL in **Settings → Pages**.

## Personalize later

- Update project cards only when you have verified details or public repository links to add.
- Replace `assets/Rutuja-Naik-Resume.pdf` when you update your resume, keeping the same filename so the download link continues to work.
- External GitHub, LinkedIn and Credly links currently point to the profile URLs included in the supplied resume.

## Content accuracy

The biography, skills, experience, education, certification status and project summaries were based on the supplied resume. No project repository links were invented. Some resume-listed technologies are explicitly marked as exposure or working knowledge.
